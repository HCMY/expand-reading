# 搜广推

来源：`ObsidianYC` 笔记库；只收录论文链接，不存放 PDF。

## CTR 预估与特征交叉

| 论文 | 主要解决的问题 |
| --- | --- |
| [Wide & Deep Learning for Recommender Systems](https://arxiv.org/abs/1606.07792) | 兼顾记忆与泛化的宽深推荐建模（笔记仅列于参考文献，未展开） |
| [Deep & Cross Network for Ad Click Predictions](https://arxiv.org/abs/1708.05123) | 用 Cross Layer 对输入做显式点乘交叉，自动学习高阶组合特征用于广告点击预估 |
| [Deep Interest Network for Click-Through Rate Prediction](https://arxiv.org/abs/1706.06978) | 用户兴趣多样且与候选 item 相关，借 attention / local activation 按候选自适应加权历史行为 |
| [Deep Interest Evolution Network for Click-Through Rate Prediction](https://arxiv.org/abs/1809.03672) | DIN 只从表层行为学习、未捕捉潜在兴趣且忽略兴趣演化，增加兴趣提取层与 AUGRU 演化层建模兴趣随时间变化 |

## LTR 与排序校准

| 论文 | 主要解决的问题 |
| --- | --- |
| [CTR Prediction for Contextual Advertising: Learning-to-Rank Approach](http://chbrown.github.io/kdd-2013-usb/workshops/ADKDD/doc/wks_submission_4.pdf) | 仅有点击数据时用 LTR 思路构造顺序 pair 对，做上下文广告 CTR 预估 |
| [From RankNet to LambdaRank to LambdaMART: An Overview](https://citeseerx.ist.psu.edu/viewdoc/download?doi=10.1.1.180.634&rep=rep1&type=pdf) | pairwise 损失只降逆序对、与 NDCG 等排序指标不一致，梳理三者演进以直接优化排序指标 |
| [Learning to Rank: From Pairwise Approach to Listwise Approach](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/tr-2007-40.pdf) | 提出 listwise 范式（ListNet），用排列/概率分布衡量与真实排序的差异，直接优化整个列表 |
| [Listwise Approach to Learning to Rank - Theory and Algorithm](http://icml2008.cs.helsinki.fi/papers/167.pdf) | ListMLE 保留排列概率特性、改用似然损失，比 ListNet 用 softmax 近似排列概率更准确 |
| [JRC: Joint Optimization of Ranking and Calibration with Contextualized Hybrid Model](https://arxiv.org/abs/2208.06164) | 模型需同时兼顾排序能力与 CTR 预估值校准能力，把一维 logits 拓展成二维并联合优化两类目标 |

## 生成式推荐

| 论文 | 主要解决的问题 |
| --- | --- |
| [HSTU: Actions Speak Louder than Words](https://arxiv.org/abs/2402.17152) | 手工数值特征瓶颈、异构模块碎片化、item-level 单监督信号限制 scaling，把行为抽象为统一序列用 decoder-only 自回归统一召回与排序 |
| [MTGR: Industrial-Scale Generative Recommendation Framework in Meituan](https://arxiv.org/abs/2505.18654) | HSTU 为完整序列建模不能用候选交叉特征导致掉点，在用户粒度 Transformer 中保留交叉特征、只在候选位置计算判别式 loss |
| [OneTrans](https://arxiv.org/abs/2510.26104) | 工业精排「先编码、后交叉」导致信息单向流动、模块碎片化且无法共用 LLM 的 KV 缓存与统一 scaling，用单一 Transformer 同时完成序列建模与特征交互 |
