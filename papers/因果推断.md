# 因果推断

来源：`ObsidianYC` 笔记库；只收录论文链接，不存放 PDF。

## Uplift 与营销决策

| 论文 | 主要解决的问题 |
| --- | --- |
| [CanniUplift](https://arxiv.org/abs/2607.05242) | 多商家发券下商家间与激励间的「蚕食」破坏 SUTVA，各店 ITE 简单加总高估平台增量，需估计平台级真实增量 GMV |
| [RERUM](https://arxiv.org/abs/2405.15301) | 收入响应零膨胀长尾使 MSE 回归失真，且投放只消费按增量排序后的头部人群，需直接优化个体间的排序关系而非只估增益值 |
| [TaQFormer](https://arxiv.org/abs/2610.26199) | 多类目折扣组合爆炸且互相耦合，线上日志带策略偏差而 RCT 小一个量级，需做结构化多维 treatment 的 uplift 估计与 OBS/RCT 融合 |
| [XTNet](https://arxiv.org/abs/2511.01641) | 干预是「多类别 × 多档位」组合，组合数指数增长且存在跨类别交叉效应，需建模组合干预并给出全局排序评价 |
| [LCM-Promo](https://arxiv.org/abs/2610.37570) | 短时促销强依赖上下文，「人群 × 促销」单元探索粒度太粗，借 LLM 预测转化阈值做 uplift 估计与促销分配 |
| [CoLA](https://doi.org/10.1145/3805712.3809750) | 补贴收益天然非对称、对称损失不匹配，且「效应估得准」不必然带来更好决策，需学出期望最低补贴阈值（回答发多少） |
| [HCL / DRM](https://arxiv.org/abs/2507.05510) | 业务真正要优化的是「增量收益 / 增量成本」这类比值型带约束聚合目标，而 CATE 类方法只估单指标、事后拼装 |
| [CausalPFN](https://arxiv.org/abs/2506.07918) | 因果估计「一事一议」需专家逐个挑估计器调参且 RCT 稀缺，用可识别模拟先验 + in-context learning 一次前向输出 ATE/CATE |

## 方法基础与评估

| 论文 | 主要解决的问题 |
| --- | --- |
| [A Survey on Causal Inference](https://arxiv.org/abs/2002.02770) | 系统梳理因果推断的方法体系 |
| [Generalized Random Forests / Causal Forest](https://arxiv.org/abs/1610.01271) | 以可插拔 score-function 指导树朝异质效应最大方向分裂的森林框架，用于估计异质处理效应 |
| [Meta-learners for Estimating Heterogeneous Treatment Effects](https://arxiv.org/abs/1706.03461) | 用 T/S/X/R-learner 等元学习器估计异质效应，缓解双模型误差累加、无法直接优化增量 |
| [Estimating individual treatment effect: generalization bounds and algorithms](https://arxiv.org/abs/1606.03976) | 用共享底层表征 + IPM 平衡处理组与对照组分布，消除混淆变量影响并给出泛化界 |
| [Learning Representations for Counterfactual Inference](https://arxiv.org/abs/1605.03661) | 观测数据存在无法避免的混淆变量时，如何学到 T/C 组可比的平衡表征 |
| [Learning to rank for uplift modeling](https://arxiv.org/abs/2002.05897) | 把 learning-to-rank 引入 uplift 建模，改进增益排序与 AUUC 类评估 |
| [Addressing Exposure Bias in Uplift Modeling for Large-scale Online Advertising](https://ieeexplore.ieee.org/document/9679134) | 大规模在线广告 uplift 建模中的曝光偏差 |
| [Can you Trust the Trend? Discovering Simpson's Paradoxes in Social Data](https://arxiv.org/abs/1801.04385) | 检测社会数据中的辛普森悖论 |
| [Targeted Learning（TMLE）](https://doi.org/10.1007/978-1-4419-9782-1) | 倾向得分模型误设会让 ATE 估计急剧变差，且单纯机器学习给不出标准误与置信区间 |
| [End-To-End Causal Effect Estimation from Unstructured Natural Language Data](https://arxiv.org/abs/2407.07018) | 从非结构化自然语言数据端到端估计因果效应（笔记仅列标题，待读） |
