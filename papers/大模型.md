## Transformer 与注意力

| 论文 | 主要解决的问题 |
| --- | --- |
| [Neural Machine Translation by Jointly Learning to Align and Translate](https://arxiv.org/abs/1409.0473) | 在神经机器翻译中联合学习对齐与翻译，提出注意力机制刻画 token 依赖，规避 RNN encoder-decoder 的长程依赖问题 |
| [Memory Networks](https://arxiv.org/abs/1410.3916) | 提出记忆网络，是 attention 中 Q/K/V 思想的来源 |
| [Attention Is All You Need](https://arxiv.org/abs/1706.03762) | 用纯 attention 构造 Transformer 做 seq2seq 翻译，解决 RNN/LSTM 串行计算并行度低、长序列内存激增与长程依赖问题 |

## LLM4Rec · Agent 自进化

| 论文 | 主要解决的问题 |
| --- | --- |
| [CORAL: An LLM-Native Harness for Production Recommender Systems](https://arxiv.org/abs/2609.02730) | 召回配额、缓存档位等非端到端控制量长期静态而环境持续漂移，把持续调参形式化为带预算约束的序贯决策，由 LLM Agent 周期级闭环调参 |
| [SR-Agent: An Experience-Driven Agentic Framework for Post-Ranking Strategy Refinement](https://arxiv.org/abs/2607.17719) | 后排序策略人工静态配置、规则失配修复跨角色需 2–3 周，用坏例驱动的自进化 Agent 闭环把周期压缩到 3–5 天 |
| [AgentX: Towards Agent-Driven Self-Iteration of Industrial Recommender Systems](https://arxiv.org/abs/2606.26859) | 工业推荐 idea→代码→A/B→归因靠工程师串行接力、吞吐按人头线性扩展，用多智能体闭环实现 idea 到上线的自迭代 |
